# Proyecto-LP
# Quiz de Física Básica

Juego interactivo de trivia sobre conceptos fundamentales de física desarrollado en Python con interfaz gráfica (`Tkinter`). El usuario selecciona sus respuestas mediante un control deslizante (`Scale`) numerado del 1 al 4.

## Requisitos
- Python 3.x instalado (incluye la librería estándar `tkinter`).

## Cómo ejecutar el programa
1. Clona o descarga este repositorio.
2. Asegúrate de que los archivos `quiz_fisica.py` y `preguntas.txt` estén en la misma carpeta.
3. Abre una terminal en esa carpeta y ejecuta:
   ```bash
   python quiz_fisica.py
